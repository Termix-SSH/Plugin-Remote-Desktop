# Changelog

## Unreleased

### Fixed

- An RDP session no longer stays behind the connecting screen when the remote screen does not change after its first frame
- A set RDP width, height or DPI is now used as entered on HiDPI screens, so older Windows servers are no longer tiny
- Pasting text into a remote desktop session works in Firefox

## 1.0.0

### Added

- RDP, VNC and Telnet from any browser
- Tabs and split screen like any other session
- Clipboard sync and file transfer through RDP drives
- Jump host support
- Session sharing and recording
- Open a host in the native Windows Remote Desktop client from the desktop app
