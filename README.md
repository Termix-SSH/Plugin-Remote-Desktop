## Overview

Remote Desktop opens RDP, VNC, Apple Remote Desktop and Telnet sessions in a tab, just like an SSH terminal. It speaks those protocols itself, so there is no guacd or anything else to install. An external guacd is still supported.

Read the [docs](https://docs.termix.site/plugins/remote-desktop) to set it up and use it.

<br />

## Features

- RDP, VNC, Apple Remote Desktop and Telnet from any browser, with nothing else to install
- Tabs and split screen like any other session
- Clipboard sync, audio, printing and file transfer through RDP drives
- Jump host support
- Session sharing and recording
- Open a host in the native Windows Remote Desktop client from the desktop app

## Support

Bugs and ideas for Remote Desktop go in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Remote-Desktop/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Remote-Desktop/issues/new?template=feature_request.yml). Report an issue on the plugin's page in the Plugins tab fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Add as much detail as you can, in English if possible. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
