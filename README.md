## Overview

Remote Desktop opens RDP, VNC and Telnet sessions in a tab, just like an SSH terminal.

Read the [docs](https://docs.termix.site/plugins/remote-desktop) to set it up and use it.

<br />

## Features

- RDP, VNC and Telnet from any browser
- Tabs and split screen like any other session
- Clipboard sync and file transfer through RDP drives
- Jump host support
- Session sharing and recording
- Open a host in the native Windows Remote Desktop client from the desktop app

## Support

Found a bug or have an idea for Remote Desktop? Open an issue in this repo: [report a bug](https://github.com/Termix-SSH/Plugin-Remote-Desktop/issues/new?template=bug_report.yml) or [request a feature](https://github.com/Termix-SSH/Plugin-Remote-Desktop/issues/new?template=feature_request.yml). The quickest way to report a bug is **Report an issue** on this plugin's page in the Termix Plugins tab, which fills in your versions for you.

Problems with Termix itself (login, hosts, credentials, sharing, sync) go in the [Termix repo](https://github.com/Termix-SSH/Termix/issues/new/choose). Not sure where it goes? Open it there and it will be moved.

Please be as detailed as possible, preferably in English. For questions, join the [Discord](https://discord.gg/jVQGdvHDrf) server.
